How it works

Three steps. About thirty seconds.

  1. 1

    Drop in your PDFs

    Drag up to three files at once. DocuChat reads each page and indexes it for search.

  2. 2

    Ask or pick a tool

    Ask in plain English, or tap Summarize, Flashcards, Quiz, Compare or Cite.

  3. 3

    Check every claim

    Click a citation chip and the PDF opens beside the chat on that page, passage highlighted.

FAQ

Questions, answered.

What happens to my documents?

Your documents are processed for your session only. The server keeps the extracted text and search index in memory for your workspace and does not write them to a database. Chats and the PDF file itself are saved in your own browser so they’re there when you come back; clear them anytime by deleting the chat or document. Text you ask about is sent to Google’s Gemini API to generate answers.

Can it make things up?

It’s instructed to answer only from the retrieved passages and to say “I couldn’t find that in your documents” otherwise. Every claim is cited so you can check it in one click. AI can still misread a passage, so verify anything important.

Which PDFs work?

Any PDF with selectable text, up to 20 MB. Scanned images without a text layer need OCR first.

What counts as a question?

Each chat message and each tool run (summary, flashcards, quiz, brief, comparison) counts as one. Research briefs and citations count one per document. If the AI fails, the question isn’t counted.

Does it work on my phone?

Yes. The app is responsive, the sidebar and PDF viewer fold away on small screens.

Is it open source?

Yes, the code is on GitHub.
